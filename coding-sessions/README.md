# Coding Sessions

The governed ticket ledger and review evidence live here. See
[`docs/TICKET-WORKFLOW.md`](../docs/TICKET-WORKFLOW.md) for the operating
contract and commands.

- `tickets/open/`: all active states, including `in-review`.
- `tickets/closed/`: founder/authorized-reviewer accepted tickets only.
- `reports/`: technical reports and independent reviewer notes.
- `human-report/`: concise founder-facing records and confirmations.
- `handoffs/`: blockers and decisions needed from a human.
- `templates/`: reusable artifact shapes.
