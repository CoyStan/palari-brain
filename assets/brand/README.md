# Palari Brain brand assets

Original artwork for Palari Brain, included under the repository's MIT
licence.

| File | Use |
|---|---|
| `palari-mark.png` | 1,254 px transparent master mark |
| `palari-mark-512.png` | Compact transparent mark for README and UI use |
| `palari-header.png` | 1,585 × 536 px README header |

The mark represents one canonical source line with recall paths that return to
verified evidence. Its negative space forms a subtle `P`.

## Generation notes

The raster artwork was generated with OpenAI's built-in image generation tool
on 2026-08-10. The mark used a flat magenta background that was removed locally
with the Codex image-generation skill's chroma-key helper. The final files were
then cropped, resized, and inspected locally.

Mark prompt, condensed:

> Create an original flat, geometric mark for an evidence-first AI memory
> kernel. Show one canonical journal line, recall paths that branch and return
> to verified source, and a subtle `P` in the negative space. Use deep ink,
> warm ivory, coral, and mint. No text, brain icon, database cylinder, cloud,
> robot, gradient, shadow, texture, or watermark.

Header prompt, condensed:

> Create an ultra-wide developer-tool header with one continuous canonical
> journal line. Small coral and mint recall paths branch to evidence nodes and
> return to the source. Use a deep ink field and the mark's restrained visual
> language. No text, brand marks, brain icon, database cylinder, robot, code,
> screenshot, or watermark.
